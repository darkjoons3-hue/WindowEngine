# WindowEngine
#
**WindowEngine** — визуальный конструктор красивых окон для Windows.
Создавайте кастомные окна с анимациями и дизайном — почти без кода.

## Что это

WindowEngine позволяет собирать окна из готовых блоков (панели, кнопки, текст),
настраивать анимации и стили, и экспортировать результат как готовое приложение
или как компонент для вставки в свой проект.

## Технологии

- Windows, C++20
- Фреймворк [ZufyUI](https://github.com/zhc9968/ZufyUI) (header-only, Direct2D)
- Тёмная тема, «плотный» стиль (в духе Unreal Engine)
